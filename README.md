RESISTOR COMBINATION CALCULATOR

1. Project Description

The Resistor Combination Calculator is a Python program designed to calculate the total resistance of resistors connected in series and parallel combinations.

2. Project Objectives

- Calculate total resistance in series.
- Calculate total resistance in parallel.
- Compare the results of both connections.
- Validate user input.

3. Features

- Accepts multiple resistor values.
- Calculates series resistance.
- Calculates parallel resistance.
- Compares both resistance values.
- Handles invalid inputs.
- Displays results to two decimal places.

4. Mathematical Formulas

Series Connection

R = R1 + R2 + R3 + ...

Parallel Connection

1/R = 1/R1 + 1/R2 + 1/R3 + ...

5. Technologies Used

- Python 3.14.6
- Visual Studio Code
- GitHub
